# Ciberseguridad-Avanzada-en-IoT-Cifrado-de-Datos-
Implemenar una arquitectura de comunicación segura de extremo a extremo para sistemas IoT mediante el cifrado simétrico de payloads (AES-128/256) o el uso de tokens de acceso (JWT), integrándolo sobre un broker MQTT previamente protegido con TLS y autenticación por credenciales, utilizando una dockerpor equipo como servidor local.
